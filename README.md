
### 🐾 Baboon Buddy – Smart Support with a Human Touch

**Baboon Buddy** is a hybrid AI-human customer support assistant built for **Baboon**, the intelligent food delivery platform. It delivers lightning-fast responses through AI while seamlessly escalating to human agents when needed—ensuring no question goes unanswered and no user feels unheard.

---

### 🚀 What We Built

We designed a **two-part system**:

#### 🧠 1. **Customer Chatbot Interface**
An intuitive, responsive chatbot that helps users:
- 📦 Track their orders  
- 💳 Resolve payment issues  
- 🍔 Get personalized food suggestions  
- 🔁 Reorder their favorite meals  
- ❓ Ask for anything else  

The AI handles common queries and dynamically decides when to escalate to a human. It also uses onboarding data, past orders, and contextual signals (like time of day) to offer smart food recommendations.

#### 💼 2. **Operator Dashboard**
We built a clean dashboard for human agents to:
- Monitor active and past conversations  
- View real-time order details  
- Respond to escalated chats  
- Analyze AI performance and chat metrics  

Agents step in only when needed, reducing workload and improving speed.

---

### 📊 Bonus: Analytics & Insights

We created a robust **Support Analytics Dashboard** to measure:
- 🤖 AI success rate  
- ⏱️ Response times (AI vs. human)  
- 🔁 Escalation reasons and frequency  
- 👤 User behavior (intents, chat volume by time, etc.)  

Visual tools like heatmaps, pie charts, and trend lines give Baboon key insights into user needs and how support can scale effectively.

---

### 🛠️ Tech Stack

- **AI Provider:** OpenAI (GPT-4 Turbo)  
- **Language:** Python  
- **Integrations:** Order Management APIs, Weather API (for recs), Escalation triggers  
- **Frontend:** CSS, Web-based chatbot UI & dashboard  
- **Design Language:** Red-themed, clean UI for brand consistency  

---

### 💡 Why Baboon Buddy?

Customer service in food delivery is often slow, robotic, or overly reliant on either AI or humans. **Baboon Buddy solves this by combining the best of both**—speed and scale from AI, empathy and context from humans.

This project shows how Baboon can **scale customer support without losing the human touch**, while enhancing user experience with **smart, timely food suggestions**.
